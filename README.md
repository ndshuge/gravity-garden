# 重力花园 · Gravity Garden

> **项目迁移公告（2026-10-10）**：本仓库作为历史版本保存。今后主要在 [游戏厅的重力花园](https://ndshuge.github.io/ndshuge-game/games/gravity-garden/) 维护；[统一源码仓库](https://github.com/ndshuge/ndshuge-game/tree/main/games/gravity-garden)。原 Git 历史和旧 Pages 入口保留。

超真实物理引擎（cannon-es 刚体物理 + three.js 渲染）的点击即玩小游戏。
暮色花园里撒下刚体，看它们真实地坠落、碰撞、堆叠；右键引爆掀飞一切；空格翻转重力。

## 怎么玩

**双击 index.html 直接玩**（无需服务器，全浏览器兼容）；或双击 **start.bat**（起服务器并自动打开浏览器）。

| 操作 | 效果 |
| --- | --- |
| 左键点击 / 按住 | 撒下刚体（球 / 方块 / 圆柱，质量按体积真实计算） |
| 右键点击 | 引爆冲击波，掀飞周围物体 |
| 方向键 / WASD | 相机前进 / 后退 / 左转 / 右转 |
| Shift / Ctrl | 相机上升 / 下降 |
| 数字键 1-9（0=10） | 在鼠标指向处批量生成对应数量 |
| R | 切换左键功能：撒下 ↔ 引力场（按住左键把物体吸向鼠标处） |
| 空格 | 循环切换重力方向（下 / 上 / 左 / 右 / 零重力） |
| G | 重置重力为向下 |
| C | 清空场景 |

## 目录

```
gravity-garden/
├── index.html      入口（UI + importmap）
├── src/main.js     全部游戏逻辑（手感层独立分区）
├── lib/            three.js / cannon-es 本地库（离线可用）
├── server.py       no-cache 静态服务器（端口 14000）
└── start.bat       双击即玩启动器
```

## 物理与手感

- 真实刚体物理：质量 = 密度 × 体积，大块头砸碎小堆；摩擦 / 恢复系数按材质对配置
- 固定步长积分 + 连续碰撞检测（CCD）防高速穿透，静止刚体自动睡眠
- 三层合成音效（撞击 / 爆炸 / 生成），音量随冲击速度
- 碰撞火花、爆炸冲击环与火球、屏幕震屏，四路反馈同帧触发
- 240 刚体上限自动回收，飞出舞台自动清理，永不卡死

## 技术备注

- 全部资源本地化（lib/），双击即玩，无需联网
- 端口被占时改 server.py 的 PORT 并同步 start.bat
- 隐藏自检：访问 `/?selftest=1` 会同步跑 360 步物理并把结果写入标题（开发用）
